2. Frontend → Static Site
New → Static Site → mismo repo.
Configura:
Build Command: npm install && npm run build
Publish Directory: dist
En Environment agrega (se incrustan al compilar):
VITE_APP_URL = https://tu-frontend.onrender.com
En Redirects/Rewrites → Add Rule (en este orden):
Source /api/* → Destination https://tu-backend.onrender.com/api/:splat → Rewrite (así /api llega al backend sin CORS)
Source /* → Destination /index.html → Rewrite (para que react-router funcione al recargar)
Deploy → abre la URL y entra con am202526 / ambar2k9.
Ojo con esto
Aiven firewall: si tu proyecto Aiven tiene lista de IPs permitidas, agrega las IPs de salida de Render (o abre temporalmente) o el backend dará timeout a la BD.
Plan Free: el backend se duerme por inactividad; la primera petición tarda ~50s en despertar.
Cada vez que cambies variables VITE_*, haz Manual Deploy → Clear build cache & deploy en el Static Site.
